# Vietnamese ASR Lab

A central repository documenting Vietnamese Automatic Speech Recognition (ASR) experiments: data preparation, model training, decoding, and evaluation across various architectures and toolkits.

## Current Implementations

- **WeNet:** U2++ Conformer training recipe, decoding and evaluation scripts, log analysis utilities, and C++ runtime reference notes.

- **Note:** Additional models and experiments (such as Zipformer) will be organized into dedicated modules as results become available.

## Getting Started

Each experiment suite contains its own setup and usage guide. Example for WeNet, refer to `instruction.md` in the recipe section and prepare your Vietnamese `train`, `dev`, and `test` datasets.
